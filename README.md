# 🎮 Tic-Tac-Toe

A beautiful Tic-Tac-Toe game with a hand-drawn notebook design, featuring both Player vs Player and Player vs Computer modes with three difficulty levels.

## ✨ Features

- 🎨 **Beautiful Design** - Hand-drawn notebook style with paper texture
- 👥 **Two Game Modes** - Player vs Player and Player vs Computer
- 🤖 **AI Opponent** - Three difficulty levels:
  - Easy: Random moves
  - Medium: Strategic moves with some randomness
  - Unbeatable: Minimax algorithm (impossible to beat!)
- 📊 **Score Tracking** - Keeps track of X wins, O wins, and ties
- ✏️ **Animated Marks** - X and O draw themselves with animation
- 🏆 **Winning Highlight** - Shows winning combination with a yellow line
- 📱 **Responsive** - Works on all screen sizes

## 🚀 Technologies Used

- **Python** - Backend game logic
- **Flask** - Web server
- **HTML/CSS** - Beautiful hand-drawn design
- **JavaScript** - Interactive game logic
- **Minimax Algorithm** - Unbeatable AI
